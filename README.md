## Deze site

Dit is de broncode van mijn persoonlijke webiste: een single-page website met Over mij, Skills,
Ervaring en Contact, gebouwd met [Astro](https://astro.build) en gehost via GitHub Pages.

- Donker thema met een geanimeerde code-achtergrond die stukjes code uit mijn eigen skillset laat
  "vallen" (`<?php`, `console.log()`, `<div>`, `wp_query`, ...)
- Volledig responsive, van telefoon tot desktop
- De code staat in [`magical-mass/`](magical-mass), met de pagina in
  [`src/pages/index.astro`](magical-mass/src/pages/index.astro), de stijlen in
  [`src/styles/global.css`](magical-mass/src/styles/global.css) en de achtergrondanimatie in
  [`src/scripts/bg-canvas.js`](magical-mass/src/scripts/bg-canvas.js)
